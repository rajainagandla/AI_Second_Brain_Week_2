# SecondSelf: A Self-Organizing AI Brain

This project addresses a common failure point in knowledge management: information goes in, but it never comes back out. Notes, bookmarks, and ideas get lost in a digital abyss, failing to compound into usable knowledge.

## Goal

The objective is to build an end-to-end system that allows you to:

1.  **Capture Anything**: A single entry point for notes, links, and files.
2.  **AI-Powered Organization**: Have an AI automatically classify, summarize, and file everything using the PARA method (Projects, Areas, Resources, Archive).
3.  **Automatic Linking**: The AI will create connections between related pieces of information by analyzing their content.
4.  **Interactive Visualization**: Render your entire knowledge base as a live, interactive, force-directed graph.
5.  **Natural Language Q&A**: Ask questions in plain English and receive answers synthesized directly from your own notes.
6.  **Deploy Publicly**: Host the final application on a public URL.

This isn't just another notes app; it's a "SecondSelf"—a brain that organizes itself and provides answers from your accumulated knowledge.

## Project Structure

The project is built in four distinct stages:

*   **The Archivist**: Creating the initial capture pipeline.
*   **The Librarian**: Building the AI processing and organization engine.
*   **The Cartographer**: Visualizing the knowledge base as an interactive graph.
*   **The Oracle**: Implementing the Q&A functionality and deploying the final application.

This repository contains the code and data for building your own SecondSelf.
